# 鼠标动就最小化向日葵

## 用途

启动监听后，程序会记录当前鼠标位置。只要检测到鼠标移动，就立即查找可见的向日葵远程窗口并最小化；窗口再次放大后，脚本仍会继续监听下一次鼠标移动。

## 使用

双击 `启动-鼠标动就最小化向日葵.bat`。

控制台显示“正在持续监听鼠标移动”后，移动鼠标即可触发最小化。按 `Ctrl+C` 可以停止监听。

## 文件

- `SunloginMouseMinimizer.ps1`：核心 PowerShell 脚本。
- `启动-鼠标动就最小化向日葵.bat`：双击启动入口。

## 说明

脚本只会最小化窗口，不会关闭向日葵进程，也不会断开远程连接。
